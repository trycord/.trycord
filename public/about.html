The project

About Trycord

Trycord is a messaging platform with an original client and server, built around one idea: communities should run themselves.

What it is

Trycord is not a hosted service that holds anyone's conversations for them. It is software you run. The server is a self-contained Node.js application you configure from environment variables and point at the database of your choice. It serves the web client itself, and it powers a desktop app that wraps the same client with automatic updates.

Because the people who run an instance own it, the defaults lean toward privacy and control: nothing is created implicitly, sensible limits are on by default, and pages are served with a restrictive security policy.

The pieces

  • backend — the Node.js server: HTTP API, WebSocket gateway, auth, and static file serving.
  • frontend — the web application: communities, channels, direct messages, profiles, and settings.
  • trycord-desktop — an Electron wrapper around the client for Windows, with installers and portable builds published from the repository.
  • public — this static website: plain, editable HTML documents shared by every instance's server.

Principles

  • Direct and dependable — a focused feature set that works, rather than a sprawling one that demands attention.
  • Complete by default — the client and server ship together and are tested against each other.
  • Honest by design — if a capability (like sending recovery email) is not configured, the app says so instead of pretending.
  • Yours to run — no managed service, no account-vendor lock-in, no implicit data stores.

Source and license

The project is developed in the open and published to github.com/trycord/.trycord. The desktop package is MIT-licensed; see the repository for details.
