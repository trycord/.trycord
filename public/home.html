What the server does

What you get

Messages, files, voice settings and moderation all live on the same instance. You install one server, not a stack of services.

#

Channels and conversations

Text channels, threads, direct messages, pinned messages, slow mode and channel-specific permissions. Messages carry reactions and attachments, including images your community names as custom emoji.

See the features !

Moderation with a record

Reports against messages, people and files become cases with frozen evidence. Warnings, timeouts, bans and appeals are enforced by the server and written to a hash-chained audit log.

How moderation works +

Files and shared work

Message attachments, community-owned workspace files, spaces, documents, boards and polls live with the community that made them. Nothing disappears when a chat scrolls away.

See the workspace

Two clients

Web, desktop and phone

The web client has three columns, a command palette and resizable panels. The phone client has three doors, long-press menus and sheets. Both use the same account and the same API.

Desktop and browser

Open the web client in a browser or install the desktop shell. The native application carries the same interface, with its own window and origin.

Get the desktop app

Phone

A separate client served at /mobile, with conversations, places and your profile as the three doors. It opens the same communities and the same messages.

Running it

Trycord is one Node service: API, gateway, jobs and the web clients on one port. The install guide takes you from a fresh machine to a signed-in account.
