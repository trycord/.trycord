Self-hostable

Talk together, on your own terms.

Trycord is private community messaging you can run yourself. Communities, channels, friends, and profiles — the same app in your browser and in a desktop app for Windows.

Open the app Get the desktop app

Everything a community needs

A focused set of features for people who want a direct, dependable place to talk.

Communities & channels

Organize conversations into communities with text channels, direct messages, friends, and presence.

Profiles that are yours

Display name, status, avatar, and banner — plus per-community nicknames so everyone knows who you are.

Moderation built in

Permissions, reports and appeals, and platform-admin tooling for the people who run an instance.

Self-hosting first

Run the server yourself on SQLite or MySQL with strict defaults: JWT sessions, rate limits, and a locked-down header policy.

One app, in the browser and on Windows

The web client is served by the server itself; the desktop app wraps the same client with auto-updates.

In your browser

Sign in at your instance's address — nothing to install. Registration asks you to accept the Terms of Service and Privacy Policy before your account exists.

On Windows desktop

An Electron app with an installer or a portable build, pointing at the instance you choose, with automatic updates from releases.

Run it your way

Configure the server from environment variables — instance name, public URL, mail for recovery, and the database. Then invite who you want.

Install the server

Docker Compose, or Node with SQLite for a small instance and MySQL when you outgrow it. A fresh install works with the defaults and no configuration at all.

Point it at a domain

Set the public URL so links in emails and invites are correct, and put a reverse proxy in front of it if you want TLS.

Invite who you want

Keep registration open, close it and invite by code, or run an instance nobody outside it can see. The choice is yours, and it is enforced by the server.

Start where you like

The documentation covers both the self-hosting path and the day-to-day of running a community.
