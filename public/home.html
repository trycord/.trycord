Private community messaging

Talk together, on your own terms.

Trycord is private community messaging you can run yourself. Communities, channels, friends, and profiles. The same app in your browser and in a desktop app for Windows.

01

Where a community lives

Conversation is organised the way a room is: spaces you name, people you keep nearby, and a place for every topic.

Communities and channels

Each community has its own channels, members, and permissions, so persistent conversation stays organised by topic.

How the pieces fit together

Direct messages and friends

One-to-one conversations outside any community, with a friends list and presence so you can see who is around.

Profiles and presence

Display name, status, avatar, and banner, with per-community nicknames so people can address you the way you prefer.

Attachments, handled safely

Images and files up to 8 MB per message, rendered sandboxed into the page rather than as raw HTML.

02

Keeping it civil

Moderation is a server responsibility, not a volunteer job. Roles and powers are enforced where the messages live, and every action leaves a record.

Granular permissions

Community roles control who can post, moderate, or administer, and the server enforces them in every request.

The moderation toolkit

Reports and appeals

Members flag problems, moderators and admins act on them, and a suspended account always has a path to appeal.

Platform administration

Designated admins manage accounts and enforce policy across the whole instance, with an audit log of every action.

Security defaults

JWT sessions, rate limits, and a locked-down header policy are on by default so a fresh instance is not a project.

03

Getting started

Run your own instance in three steps. Nothing is created implicitly and a fresh install works with the defaults.

Install the server

Docker Compose, or Node with SQLite for a small instance and MySQL when you outgrow it. A fresh install works with the defaults and no configuration at all.

Point it at a domain

Set the public URL so links in emails and invites are correct, and put a reverse proxy in front of it if you want TLS.

Invite who you want

Keep registration open, close it and invite by code, or run an instance nobody outside it can join. The choice is yours, and the server enforces it.

04

Run it your way

An instance is configured from environment variables, and every setting is in one place in the admin console. Self-hosting is the product, not a plan.

Configure from the environment

Instance name, public URL, mail for recovery, and the database are environment variables, with a configuration centre in the app to review them.

The configuration reference

SQLite or MySQL

Start small on SQLite with zero setup, move to MySQL for production, and choose the profile with one setting.

Mail when you want it

Password recovery and email verification work in log mode for development and SMTP for real sends, so the instance never fakes a delivery.

One app, two surfaces

The web client is served by the server itself, and the desktop app wraps the same client with automatic updates from releases.
