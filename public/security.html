Trust & security

Security

Trycord keeps authentication, authorization, uploads, sessions and community moderation behind explicit server-side controls.

Authentication

Passwords are hashed server-side. Sessions are token based and can be revoked individually or globally.

Authorization

Community permissions and platform administration are enforced by the server. The client only presents controls the current session can use.

Uploads

Profile media and message attachments are served through authenticated routes rather than a public upload directory.

Reporting

Trust & Safety actions, reports and appeals are recorded by the server and exposed only through authorized endpoints.
