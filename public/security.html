Security

Security

Trycord enforces who can do what on the server, not in the browser. The server decides; the interface only shows you what you are allowed to do.

Sign-in

Passwords are hashed before they are stored. Sessions use tokens that can be revoked one at a time or all at once.

Permissions

Community roles and admin powers are checked on the server. The app never decides for itself what you can do.

Uploads

Profile pictures and file attachments are served through signed routes, not a public folder anyone can browse.

Moderation

Reports, appeals and admin actions are written to a server-side log. Only people who are allowed to see them can.
