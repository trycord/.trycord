Get Trycord

Download

Trycord is the same app in your browser and on your desktop. There is nothing to install to get started — but a Windows desktop app is available if you prefer a standalone window.

Use it right now (no install)

Open the app in any modern browser at your instance's address. Open the app

Windows desktop app

  • Installer — the NSIS setup: choose your directory, get Start-menu and desktop shortcuts, and benefit from automatic updates.
  • Portable — a single portable executable that needs no installation.

Download the latest builds from the repository's Releases page (files are named Trycord.exe and TrycordPTB.exe). Artifacts are Windows x64. Linux (AppImage) and macOS builds are produced from the same project when released.

First run

On launch the desktop app opens the client and lets you choose the instance to connect to. The eye icon toggles password visibility and the registration screen asks you to accept the current Terms of Service Official instance terms and Privacy Policy before your account is created. See the documentation if you also want to run your own server.
